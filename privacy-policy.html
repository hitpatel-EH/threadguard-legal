ThreadGuard AI

Privacy Policy

1. Introduction

ThreadGuard AI is a security analysis application designed to help identify potentially harmful or suspicious content on Threads, including phishing, scams, malicious URLs, impersonation, social engineering, and other security-related indicators.

This Privacy Policy explains what information ThreadGuard AI may process, how that information is used, and how users can request deletion of applicable data.

2. Information We Process

Depending on the features used and the permissions granted through the Threads API, ThreadGuard AI may process information associated with Threads posts, including:

  • Threads post ID
  • Threads username
  • Post text
  • Post timestamp
  • Post permalink
  • Publicly available security-related indicators contained in posts
  • ThreadGuard AI analysis results

3. Threads API

ThreadGuard AI uses the official Threads API provided by Meta to access Threads information permitted by the application and the permissions granted to the authorized user.

ThreadGuard AI does not use web scraping to collect Threads content.

4. How We Use Information

Information processed by ThreadGuard AI is used for security analysis and application functionality, including:

  • Detecting potentially malicious or suspicious content
  • Identifying phishing and scam indicators
  • Analyzing suspicious URLs
  • Detecting social engineering patterns
  • Identifying possible impersonation indicators
  • Generating explainable security findings
  • Calculating a security risk score
  • Displaying analysis results in the ThreadGuard dashboard

5. Security Analysis

ThreadGuard AI may combine rule-based detection, machine learning analysis, and threat intelligence information to produce security analysis results.

The analysis is intended to provide security information and does not guarantee that a post, account, URL, or other content is safe or malicious.

6. Data Storage

Depending on the application configuration, analyzed information and security analysis results may be stored in the ThreadGuard AI application database for monitoring, analysis history, reporting, and security research purposes.

ThreadGuard AI does not intentionally store a user's Threads password.

7. Access Tokens and Authentication

ThreadGuard AI uses authentication mechanisms provided by Meta for authorized access to the Threads API.

Access tokens are used to authenticate API requests and are intended to be stored securely by the application.

8. Third-Party Services

ThreadGuard AI may use third-party security or infrastructure services when enabled by the application configuration.

Such services may process information necessary to perform security analysis or application operations.

9. Data Retention

Information may be retained only for as long as necessary to provide ThreadGuard AI functionality, maintain analysis history, support monitoring, generate reports, or satisfy applicable legal or security requirements.

10. Data Deletion

Users may request deletion of applicable information processed or stored by ThreadGuard AI.

For information about requesting deletion, please visit:

ThreadGuard AI Data Deletion Instructions

11. Changes to This Privacy Policy

This Privacy Policy may be updated when ThreadGuard AI functionality, data processing practices, or applicable requirements change.

12. Contact

For privacy-related questions or data deletion requests, please contact the ThreadGuard AI project administrator through the contact information provided by the application owner.
